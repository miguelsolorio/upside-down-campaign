Touch controls check

The on-screen controls the game ships, drawn by the game's own code at the game's pixel size. Every button is a keycap: a dark top over a darker lip, and pressing slides the top down. Phones are shown at real CSS size, and the game and every button sit exactly where the shipped layout puts them.

  • Stick: the ring stays put and the knob follows the left thumb
  • A: attack, confirm, light
  • B: special, back
  • Arrows: swap hero
  • d20: party burst, gold when ready
  • Top keys: skip (lit only during dialogue) and pause
